# Hermes Tweet

Hermes Tweet is a native Hermes Agent plugin for X/Twitter research and controlled action workflows.

## Install

Install the Claude Code discovery skill from this marketplace:

```bash
/plugin install hermes-tweet
```

Use the canonical source for the Hermes Agent plugin runtime:

```bash
https://github.com/Xquik-dev/hermes-tweet
```

## Included Skill

| Skill | Purpose |
|-------|---------|
| `hermes-tweet` | Find, install, and safely operate the native Hermes Tweet plugin for Hermes Agent |
